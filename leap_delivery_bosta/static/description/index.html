Key Features

Everything you need to ship with Bosta — fully embedded in Odoo

🚚

Select Bosta on Sales Orders

Choose Bosta as the shipping carrier directly on the Sale Order. Configure shipment type, package size, COD, and open-package inspection per order.

⚡

Auto Shipment Creation

When you validate a delivery order, Bosta creates the shipment automatically via API. Shipment ID and tracking number are saved back to the delivery record.

🖨

Air Waybill (AWB) Printing

Download and print the official Bosta AWB PDF with one click. The label is attached to the delivery order and stored in Odoo for future reference.

📡

Real-Time Tracking

Refresh the shipment status directly from Bosta's API. Track from Created → Picked Up → In Transit → Out for Delivery → Delivered, with chatter history.

💰

Cash on Delivery (COD)

Enable COD on any shipment and specify the amount to collect. The COD value is transmitted to Bosta automatically during shipment creation.

📅

Schedule Courier Pickup

Open the pickup wizard to schedule a Bosta courier pickup for one or multiple orders. Specify date, time slot, contact person, and address.

❌

Cancel Shipments & Pickups

Cancel Bosta shipments or scheduled pickups from Odoo with a single action. The cancellation is reflected in both systems instantly.

🔗

Smart Sale Order Button

A smart button on the sale order shows live Bosta tracking status. Click to drill down into the delivery order for full shipment details.

Quick Setup Guide

Be live with Bosta in under 5 minutes

Install the Module

Go to Apps, search for leap_delivery_bosta, and click Install. The Bosta carrier is created automatically.

Enter Your API Key

Navigate to Inventory → Configuration → Delivery Carriers → Bosta. Paste your Bosta API key and select Production or Staging.

Test the Connection

Click "✓ Test Connection" to verify your API key is valid before going live.

Set Defaults

Choose your default shipment type (SEND / EXCHANGE…) and package size (SMALL / MEDIUM / LARGE / X_LARGE) on the carrier form.

Create a Sale Order

On a Sales Order, select Bosta as the delivery carrier. Adjust per-order options such as COD amount, open-package inspection, and shipment type.

Validate & Ship

Validate the delivery order. Bosta creates the shipment instantly. Download the AWB, track the parcel, and schedule a pickup — all from Odoo.

تثبيت الوحدة

انتقل إلى التطبيقات، ابحث عن leap_delivery_bosta، ثم انقر تثبيت. يُنشأ ناقل بوستا تلقائياً.

إدخال مفتاح API

انتقل إلى المخزون ← الإعدادات ← ناقلات التوصيل ← بوستا. الصق مفتاح API واختر بيئة الإنتاج أو الاختبار.

اختبار الاتصال

انقر "✓ اختبار الاتصال" للتحقق من صحة مفتاح API قبل البدء.

ضبط الإعدادات الافتراضية

اختر نوع الشحنة الافتراضي (SEND / EXCHANGE…) وحجم الحزمة (SMALL / MEDIUM / LARGE / X_LARGE) في نموذج الناقل.

إنشاء أمر البيع

في أمر البيع، اختر بوستا كناقل شحن. اضبط خيارات كل طلب: مبلغ الدفع عند التسليم، الفحص قبل القبول، ونوع الشحنة.
